# Исправления по независимому аудиту — 0.6.0

## Риск

Уменьшение позиции без переворота разрешено, даже если остаток превышает лимиты
позиции, gross, сектора или кластера. Лимиты размера заявки, дневного оборота,
блокировок, денежных средств и активных заявок сохраняются. Это не безусловный
аварийный bypass. Закрытие шорта требует доступных денег; резерв не отключается.

## Intraday

Снимок брокера теперь включает executed_operations за текущий торговый день.
Цена входа восстанавливается по исполненным операциям: частичные исполнения
усредняются, частичное закрытие сохраняет себестоимость и время первого исполнения,
полное закрытие завершает lifecycle. Дубли operation_id игнорируются.

Стоп, тейк и время удержания используют эти данные, а не цену сигнала.
При несовпадении количества восстановленных единиц с брокерской позицией
создаётся защитный выход missing_entry_state. Это относится к отдельному
intraday sandbox-счёту; нельзя применять к защищённым бумагам реального ИИС.

Старые сохранённые снимки без executed_operations не подходят для продолжения
ведения позиций: сначала требуется новый broker-portfolio-snapshot.
Счётчик signals остаётся консервативным лимитом попыток входа, включая неисполненные
заявки; он не является счётчиком фактических сделок. Фактические сделки берутся из
брокерских операций. Брокерские stop orders не добавлены: защита требует работающего
таймера и доступности API; при сбое сервера гарантировать выход нельзя.

## Календарь

Запрос и отображение начинаются с начала текущего дня МСК. Неожиданные поля
ответа вызывают ошибку; {} допустим как стандартное пустое protobuf-сообщение.
Для отчётов идентичность задаётся UID и отчётным периодом, поэтому перенос даты
обновляет событие и записывается в revisions. Дивиденды пока идентифицируются по
дате реестра: перенос даты реестра требует проверки, не считается автоматически
связанной редакцией. Пустой список не доказывает отсутствие событий.

calendar-status возвращает exit=2 для неполного/устаревшего календаря.
start включает calendar.timer только при наличии отдельного read-only токена.
stop отключает календарь, diagnose показывает статус; update сохраняет активность
таймера, uninstall удаляет unit-файлы.

## Не является подтверждением доходности

Существующий исторический бэктест не соответствует новой версии и должен быть
пересчитан. Прямые API/systemd проверки на Ubuntu и sandbox end-to-end ещё нужны
после установки. Автоматические новости, санкции и торговое управление по
биржевому календарю не включены. Production observer остаётся без исполнения.
