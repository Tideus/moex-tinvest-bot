# План торгового бота MOEX + ALGOPACK + T-Invest

Версия: 1.0  
Дата: 14 августа 2026 года  
Часовой пояс системы: Europe/Moscow

Этот пакет описывает исследовательский и инженерный план создания торгового бота для акций Московской биржи. Рыночные данные и аналитика поступают из MOEX ISS и ALGOPACK через `moexalgo`, а заявки исполняются через T-Invest API.

## Состав пакета

1. [00-master-plan.md](00-master-plan.md) — полный последовательный план и критерии перехода между этапами.
2. [01-architecture-and-data.md](01-architecture-and-data.md) — архитектура, компоненты, данные, идентификаторы и хранение.
3. [02-strategy-and-geopolitics.md](02-strategy-and-geopolitics.md) — базовая стратегия, часовой цикл и геополитический риск-фильтр.
4. [03-testing-plan.md](03-testing-plan.md) — модульные, интеграционные, исторические, replay, sandbox, shadow и live-тесты.
5. [04-operations-security-budget.md](04-operations-security-budget.md) — эксплуатация, безопасность, мониторинг, комиссии и стартовый капитал.
6. [05-roadmap-and-checklists.md](05-roadmap-and-checklists.md) — дорожная карта, Definition of Done и чек-листы запуска.
7. [06-sources.md](06-sources.md) — официальные источники и исследовательские материалы.

## Основное проектное решение

- Python 3.12.
- Официальная библиотека `moexalgo` для MOEX/ALGOPACK.
- Актуальный официальный SDK T-Bank для T-Invest API.
- PostgreSQL для состояния, истории сигналов, заявок и аудита.
- Медленная long-only momentum/trend-стратегия как первая проверяемая гипотеза.
- Пересчёт после закрытия каждой часовой свечи.
- Геополитика используется как риск-фильтр: блокирует или уменьшает риск, но не создаёт заявку напрямую.
- Постоянный контроль заявок и брокерского состояния работает отдельно от часового анализа.
- Codex используется для разработки, анализа и отчётности, но не входит в критический контур исполнения.

## Границы документа

План не содержит гарантии прибыльности. Числовые параметры стратегии и риска являются стартовыми исследовательскими значениями и должны пройти историческую, out-of-sample, sandbox, shadow и ограниченную live-проверку.

Материал предназначен для исследования и не является индивидуальной инвестиционной рекомендацией.
