# Следующая проверка преимущества стратегии

Дата фиксации: 28 ноября 2026. Это план исследования, не торговый конфиг.
PROD, лимиты, universe рабочих стратегий и расписание не изменяются.

## Что уже известно

Период 13–27 ноября использован для диагностики, поэтому не считается новым
независимым тестом после выбора улучшений по его результатам. Intraday sandbox:
валовой денежный результат завершённых позиций +15,34 ₽, комиссия 254,595651 ₽,
чистый денежный результат −239,255651 ₽. Сумма опубликованных дневных результатов
отличается на 0,000002 ₽ из-за округления. Удвоение только комиссии даёт
−493,851302 ₽; это ещё не стресс удвоенного спреда и проскальзывания.

У LONG не было новых BUY в этом периоде. Небольшое изменение капитала старой
позиции не является проверкой прибыльности новых входов LONG.

## Сравнение исполнения

1. Фиксировать один набор сигналов с временем доступности исходных данных.
   Контроль SBER/ROSN/CHMF и расширение 21 бумаги показывать отдельно.
2. Для каждого сигнала сравнить пассивный лимит и исполнимый лимит у встречной
   цены при одинаковом капитале, времени решения и задержке.
3. Сохранить исходные bid/ask, размеры уровней, шаг цены, размер лота,
   календарь, ограничения инструмента и точную тарифную ставку каждого контура.
4. Касание не считать сделкой. При отсутствии очереди и потока сделок результат
   пассивной заявки обозначать модельным/неопределённым, а не подтверждённым.
   Учесть частичное исполнение, TTL, гэпы и неисполненные сигналы.
5. Выходы сравнивать на одинаковых входах. Отдельно показать эффект отбора
   исполненных заявок: выгодные сделки не должны отбираться задним числом.
6. Отчёт: покрытие входов, fill rate, spread/slippage/commission, net expectancy,
   просадка, время в позиции, оборот, число сессий и уникальных сигналов.

## Независимая проверка

Следующий отрезок начинается с первой подтверждённой календарём сессии после
фиксации этой версии гипотез. Первые 20 полностью завершённых сессий — минимальный
плановый горизонт, не гарантия статистической достаточности. Не завершать тест
досрочно только потому, что результат оказался положительным.

До начала сравнения зафиксировать варианты и издержки. После начала не менять
их; новая версия требует отдельной серии. Исторические правила shortability,
комиссий и дивидендов должны иметь дату действия, иначе отдельный флаг неполноты.
Временные окна не переносятся через ночь/перерыв для получения удобной цены.

Обычные расходы и двойные расходы показывать одновременно. Доверительные
интервалы считать по блокам торговых дней, не по повторяющимся 5-минутным сигналам.
Если интервал ожидаемого net включает существенный убыток, вывод — недостаточно
доказательств, а не доказанная прибыльность. Win rate 70% сам по себе не критерий.

Существующее shadow-наблюдение может продолжать собирать данные; этот документ
не запускает новые службы и не меняет замороженный исследовательский протокол.
Текущие markout по стакану — движение после решения, не реализация обеих моделей
исполнения и не портфельный P&L. Для честного сравнения лимитных исполнений нужны
перечисленные выше данные и отдельная модель; нельзя выдать уже имеющиеся markout
за завершённый RES03/RES04 на независимом периоде.

## Допуск

Устранение ошибок журнала и подтверждение BUY → стоп решают техническую часть.
Выбор стратегии требует отдельного результата описанного теста. Реальная пробная
сделка на ИИС, если оператор разрешит её отдельно, не доказывает прибыльность и
не даёт разрешения автоматически включить весь intraday в PROD.
